# Mimin Omnichannel Widget

A Vite 8 + React launcher for embedding Mimin's existing omnichannel web chat on external websites. The launcher uses a shadow root and `mimin-` prefixed CSS classes; the full chat runs in an iframe at `/web-chat/embed/:username`. The launcher uses plain CSS rather than Tailwind, so no host Tailwind configuration is needed. Widget colors, icon, and optional title come from the saved Website credential (`template_data`) in Mimin, not from the embed code. The launcher appears only after the embedded chat confirms it is ready.

## Develop

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

The Vite playground is at `http://localhost:5173`. Run the Mimin app separately and set the playground's App URL to its origin.

## Build and host

```sh
npm run build
npm run build:hosted
```

`build` creates `dist/omnichannel.js` and `dist/omnichannel.css`. `build:hosted` also copies both files to the sibling Mimin app under `public/omnichannel-widget/v0.1.1/`. To use another destination, set `MIMIN_HOST_PUBLIC_DIR` to the public widget directory. The Mimin app serves those files across origins.

Version 0.1.1 is an unpublished local test candidate. Run `npm run build:hosted`, then run `next dev` in the Mimin app. The Website → Script tab uses the local 0.1.1 file in development. Production continues to show the published npm 0.1.0 URL until 0.1.1 is tested and published.

## Embed

Use the snippet generated by Mimin's Website → Script tab. Its shape is:

```html
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/mimin-omnichannel-widget-react@0.1.0/dist/omnichannel.js"
  data-mimin-username="YOUR_USERNAME"
  data-mimin-website-id="YOUR_WEBSITE_ID"
  data-mimin-app-url="https://YOUR_MIMIN_APP"
></script>
```

This external module tag initializes the widget without inline JavaScript. For custom integration, import `{ Omnichannel }` from the same module URL and call `Omnichannel.init({ username, websiteId, appUrl })`. `init()` returns `{ open, close, destroy }`; the same methods also exist on `Omnichannel`. Calling `init()` again replaces the previous instance. `position` (`left` or `right`) and `zIndex` are optional. Appearance comes from the saved Website credential.

The package can also be installed in a JavaScript project:

```sh
npm install mimin-omnichannel-widget-react
```

```js
import { Omnichannel } from 'mimin-omnichannel-widget-react'

Omnichannel.init({
  username: 'YOUR_USERNAME',
  websiteId: 'YOUR_WEBSITE_ID',
  appUrl: 'https://YOUR_MIMIN_APP',
})
```

To serve the JavaScript from your own Mimin app instead of the npm CDN, use the following module tag. The app must serve the matching JavaScript and CSS files:

```html
<script
  type="module"
  src="https://YOUR_MIMIN_APP/omnichannel-widget/v0.1.0/omnichannel.js"
  data-mimin-username="YOUR_USERNAME"
  data-mimin-website-id="YOUR_WEBSITE_ID"
  data-mimin-app-url="https://YOUR_MIMIN_APP"
></script>
```

The widget loads its stylesheet from the Mimin app origin, so that app must serve `/omnichannel-widget/v0.1.0/omnichannel.css` even when the JavaScript comes from npm or a CDN. If the embedding site uses HTTPS, the Mimin app URL must also use HTTPS; browsers block HTTP widget resources as mixed content.

The script stores a random visitor ID under the embedding site's own `localStorage` origin, scoped by Mimin host, username, and Website ID. Each domain therefore has a separate conversation identity. The iframe does not require third-party cookies. Greeting completion and language preference are persisted on the embedding domain by verified `postMessage` events from the iframe.

The Mimin app allows framing only the dedicated `/web-chat/embed/*` route. A customer's Content Security Policy needs the script host in `script-src` and the Mimin app origin in `style-src`, `connect-src`, and `frame-src`. A custom widget icon hosted elsewhere also needs its origin in `img-src`. The widget needs no `unsafe-inline` exception. Normal `/web-chat/*` and dashboard pages keep `X-Frame-Options: SAMEORIGIN`.

## Release

After publishing 0.1.1 to npm, update the dashboard's production CDN version and the published examples above to 0.1.1. Keep the JavaScript and CSS versions aligned. `prepack` builds the JavaScript, CSS, and TypeScript declarations before npm creates the tarball.
