# Mimin Omnichannel Widget

A Vite 8 + React launcher for embedding Mimin's existing omnichannel web chat on external websites. The launcher uses a shadow root and `mimin-` prefixed CSS classes; the full chat runs in an iframe at `/web-chat/embed/:username`. The launcher uses plain CSS rather than Tailwind, so no host Tailwind configuration is needed. Widget colors, icon, and title come from the saved Website credential (`template_data`) in Mimin, not from the embed code.

## Develop

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

The Vite playground is at `http://localhost:5173`. Run the Mimin app separately and set the playground's App URL to its origin.

## Build and host

```sh
npm run build
npm run build:hosted
```

`build` creates `dist/omnichannel.js` and `dist/omnichannel.css`. `build:hosted` also copies both files to the sibling Mimin app under `public/omnichannel-widget/v0.1.0/`. To use another destination, set `MIMIN_HOST_PUBLIC_DIR` to the public widget directory. The Mimin app serves those files across origins. Deploy both files together with the Mimin app changes.

## Embed

Use the snippet generated by Mimin's Website → Script tab. Its shape is:

```html
<script
  type="module"
  src="https://YOUR_MIMIN_APP/omnichannel-widget/v0.1.0/omnichannel.js"
  data-mimin-username="YOUR_USERNAME"
  data-mimin-website-id="YOUR_WEBSITE_ID"
  data-mimin-app-url="https://YOUR_MIMIN_APP"
></script>
```

This external module tag initializes the widget without inline JavaScript. For custom integration, import `{ Omnichannel }` from the same module URL and call `Omnichannel.init({ username, websiteId, appUrl })`. `init()` returns `{ open, close, destroy }`; the same methods also exist on `Omnichannel`. Calling `init()` again replaces the previous instance. `position` (`left` or `right`) and `zIndex` are optional. Appearance comes from the saved Website credential.

The script stores a random visitor ID under the embedding site's own `localStorage` origin, scoped by Mimin host, username, and Website ID. Each domain therefore has a separate conversation identity. The iframe does not require third-party cookies. Greeting completion and language preference are persisted on the embedding domain by verified `postMessage` events from the iframe.

The Mimin app allows framing only the dedicated `/web-chat/embed/*` route. A customer's Content Security Policy needs the Mimin origin in `script-src`, `style-src`, `connect-src`, and `frame-src`. A custom widget icon hosted elsewhere also needs its origin in `img-src`. The widget needs no `unsafe-inline` exception. Normal `/web-chat/*` and dashboard pages keep `X-Frame-Options: SAMEORIGIN`.

## Release

Keep the version in `package.json`, the dashboard snippet, and the hosted path aligned. Bump them together for a new widget release. The ES module can also be published to npm for a CDN such as jsDelivr; publication is separate from the local build.
